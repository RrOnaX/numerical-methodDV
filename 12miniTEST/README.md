## Содержание и ход выполнения работы

1. **Создание массива и проверка атрибутов (`shape`, `ndim`, `size`, `dtype`)**
   * Создан одномерный массив `np.arange(24)` и преобразован в двумерную матрицу `M` формы `(6, 4)`.
   * Проверены базовые метаданные массива: размерность `(6, 4)`, количество измерений `2`, общее число элементов `24` и тип данных `int64`.

2. **Преобразование формы (`reshape`) и проверка целостности данных**
   * Выполнена последовательная перестройка формы массива: `(6, 4) → (4, 6) → (2, 3, 4) → (24,)`.
   * С помощью функции `np.array_equal` подтверждено, что изменение формы меняет только шаги индексации (`strides`) в метаданных, не затрагивая и не копируя сами значения в памяти.

3. **Исследование срезов (`view` против `copy`)**
   * Извлечён срез третьего столбца `M[:, 2]` и изменено его первое значение.
   * Экспериментально подтверждено, что обычный срез в NumPy возвращает представление (`view`), ссылающееся на исходную область памяти (изменение среза меняет оригинальную матрицу `M`). После проверки исходное значение восстановлено.

4. **Фильтрация по условию (булева маска) и агрегация**
   * Сформирована логическая маска `M > 10` для отбора элементов в одномерный массив.
   * Вычислено среднее арифметическое отфильтрованных элементов (`17.0`).

5. **Центрирование строк с помощью `broadcasting`**
   * Вычислено среднее значение по каждой строке (`axis=1`) с сохранением размерности (`keepdims=True`, форма `(6, 1)`).
   * Выполнено вычитание строчных средних из исходной матрицы `M` без использования циклов. Итоговый массив сохранил форму `(6, 4)`, а сумма элементов по каждой строке стала равна `0`.
